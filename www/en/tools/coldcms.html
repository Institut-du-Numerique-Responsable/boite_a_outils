Coldcms

A CMS built for ecological performance. ColdCMS is a Django project based on Wagtail CMS and Bulma CSS Framework. Admin can edit websites through intuitive and user-friendly interface. Different types of pages are pre-designed, which allows you to have a beautiful website without spending hours on it. ColdCMS is specially designed for people who want to reduce the impact of their use of digital technologies on the environment. The client's website consists of static pages, built with the Wagtail Bakery. The pages of the site are generated and updated as necessary (for example when the administrator publishes or modifies content). Among other optimizations, CSS file sizes are reduced and unused CSS code is removed, using PurgeCSS and clean-css. ColdCMS supports Python> = 3.6.
