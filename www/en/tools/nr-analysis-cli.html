nr-analysis-cli

A Node.js CLI that audits web pages for eco-design and accessibility. Reproduces the GreenIT-Analysis Chrome extension via Puppeteer/Chromium to compute environmental metrics (CO₂ emissions, water use, EcoIndex score) and check compliance with best practices across sobriety, accessibility, cybersecurity and server performance.
