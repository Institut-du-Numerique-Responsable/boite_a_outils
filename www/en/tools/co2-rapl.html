CO2_RAPL

A Bash script that monitors a Linux server's CPU energy consumption via Intel RAPL and converts it into estimated CO₂ emissions. Provides real-time power measurement in Watts and computes the corresponding carbon impact using the regional electricity grid's emission factor — useful for assessing a server infrastructure's environmental footprint.
