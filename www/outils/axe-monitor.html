Axe monitor

ax Monitor® est un outil d'analyse et de création de rapports au niveau de l'entreprise qui peut évaluer l'accessibilité Web de sites Web entiers, y compris les zones protégées par mot de passe. ax Monitor peut implémenter des scripts de cas d'utilisation, autoriser des options de rapport personnalisées basées sur les directives WCAG ou Section 508 et permettre une surveillance programmée de l'accessibilité sur des projets de toute envergure ou complexité. Il est conçu pour fonctionner avec l'extension de navigateur ax DevTools pour Chrome et Firefox. Il existe une version en API de Axe Monitor
