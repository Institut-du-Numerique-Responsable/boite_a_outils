Code de conduite européen sur les datacentres

Le CoC pour l'efficacité énergétique des Data Centers a été établi pour répondre à l'augmentation de la consommation d'énergie dans les Data Center et à la nécessité de réduire les incidences sur l'environnement, l'économie et la sécurité de l'approvisionnement énergétique.
