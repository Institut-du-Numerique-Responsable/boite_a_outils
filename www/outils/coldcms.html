Coldcms

Un CMS construit pour des performances écologiques. ColdCMS est un projet Django basé sur Wagtail CMS et Bulma Cadre CSS. L'administrateur peut éditer des sites Web via une interface intuitive et conviviale. Différents types de pages sont préconçus, ce qui permet avoir un beau site web sans y passer des heures. ColdCMS est spécialement conçu pour les personnes qui souhaitent réduire l'impact de leur utilisation des technologies numériques sur l'environnement. Le site Web du client se compose de pages statiques, construites avec la boulangerie Wagtail. Les pages du site sont générés et mis à jour si nécessaire (par exemple lorsque l'administrateur publie ou modifie du contenu). Entre autres optimisations, la taille des fichiers CSS est réduite et le code CSS inutilisé est supprimé, en utilisant PurgeCSS et clean-css. ColdCMS prend en charge Python >= 3.6.
