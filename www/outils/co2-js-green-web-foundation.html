CO2.js (Green Web Foundation)

Bibliothèque JavaScript qui convertit un volume de données transférées en émissions de CO₂, avec le choix du modèle de calcul et la prise en compte de l'intensité carbone du réseau électrique. Permet d'afficher l'empreinte d'une page directement dans l'application.
