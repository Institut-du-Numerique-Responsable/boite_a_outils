Cloud foundry footprint

Script Python qui estime l'empreinte carbone de toutes les applications Cloud Foundry (CF) d'une organisation. Le script utilise des commandes de base « cf cli » pour compter le nombre de conteneurs en cours d'exécution par espace. Ceci est ensuite multiplié par une consommation énergétique moyenne estimée
